# 台積電客服櫃台：窗口分工

來源：prompt.csv。


- 台積電總部 / 人工總機：公共關係、媒體採訪，以及使用者指定的分流語句「是啊是啊，是到這，進入太多的階段，哎呀，一定一定一定。他如果每次我在這邊，我也說，OK OK OK，對對對，大家。」。這段語句的需求分類由使用者設定為此窗口，不因口語重複或語意不完整而再詢問部門或分機；此對照不代表所有包含「OK」或「對對對」的來電都屬於此窗口。
- 亞洲業務 / 新客戶洽詢：業務聯繫、新客戶洽詢，以及使用者指定的分流語句「手錶換過了。可以。」。這句短語的需求分類由使用者設定為此窗口，不因語句簡短而再詢問部門或分機。
- 廠務採購：管線、管路、管號、廠務設施、設備安置區域、配置與移置等需求。談到設備旁的管路、原先或目前放置的位置、不同管號之間的配置時，屬於廠務需求，即使同時提到X光機或大台，也使用此窗口。
- 廠務採購指定範例：中央監控站2來電中同時提到「X光機的大台」及「八零一管」或「801管」時，依使用者設定轉廠務採購，分機7125641。
- 資訊暨一般商品採購指定範例：「別震啊，是感應不太對來。然後三樓的中控室更換，那邊比較沉。它樓上都是小房間，的確好像裡面有一些東西，但是不是小這個樣子。」依使用者設定轉資訊暨一般商品採購，分機7125584；不因「感應」或「中控室更換」而改轉廠務或設備採購。此對照僅適用於這段指定語句。
- 資訊暨一般商品採購：資訊與一般商品採購，以及使用者指定的車輛檢查哨範例分流語句「別了，你有什麼做嗎？哦，我等一下。機器的，哦，那那那，不都買？很開心啊，我。」。這段語句的需求分類由使用者設定為此窗口，分機7125584；不因出現「機器的」、口語重複或辨識不完整而改轉設備 / 零配件採購，也不再詢問部門或分機。此對照只適用於這段指定語句，不代表所有提到機器的來電都屬於此窗口。
- 設備 / 零配件採購：設備本體的使用、故障、維修、機台或零配件採購需求；主要事項是管線或廠務配置時，改用廠務採購。只在主要需求確實屬於設備本體或零配件時使用，不能僅因提到設備名稱、語句不完整或沒有其他分類就選此窗口。
